# Flappy Bird Clone (Python + OpenGL)

A simple Flappy Bird game created with Python and OpenGL. The game features
smooth rendering, pipe generation, collision detection, and a scoring system.

## Features
- Smooth OpenGL rendering
- Gravity and jump physics
- Randomly generated pipes
- Score counter
- Collision detection
- Top menu bar with Back, Pause, and Exit buttons

## Tech Used
- Python 3
- OpenGL

## Requirements
- Python 3 installed

## How to Run
1. Clone the repository.
2. Make sure the `OpenGL` folder is in the same directory as `Flappy.py`, and then open this directory in a code editor like VSCode.
3. Run the game by either clicking on the play button in your code editor or typing `python Flappy.py` in the terminal.

## Controls
- Up Arrow Key: Jump

## Menu Bar (Need to click the items)
- Back Arrow: Restart the game
- Pause: Pause the game
- X: Close/Exit the game window
